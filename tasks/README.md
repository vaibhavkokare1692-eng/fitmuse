# Tasks

This folder routes agents with low copy-paste.

## Workflow

1. Read `docs/ai/PROJECT_STATE.md`.
2. Read `docs/ai/PRODUCT_PRINCIPLES.md`.
3. Read `docs/ai/RELEASE_RULES.md`.
4. Read assigned task in `tasks/now` or `tasks/next`.
5. Report findings to `reports/<agent>/`.

## Folders

- `tasks/now`: active approved task.
- `tasks/next`: planned future tasks.
- `tasks/done`: completed task notes.

## Rules

- Do not deploy or tag unless the task explicitly approves it.
- Do not commit screenshots unless approved.
- Keep reports short and operational.
