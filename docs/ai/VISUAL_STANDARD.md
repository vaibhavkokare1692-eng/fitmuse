# Visual Standard

FitMuse should feel like premium consumer fashion-tech, not a demo.

## Direction

- Fewer words.
- Strong visual proof early.
- Editorial flat-lay direction.
- Clean linen, sand, stone, warm-neutral surfaces.
- Outfit composition should make the board feel desirable before users read details.

## Current Rule

- Abstract visuals are acceptable only as temporary placeholders.
- Style-reference images must be labeled honestly.
- Recommended label: `Style reference - not exact product photos`.

## Do Not Use

- No scraped retailer images.
- No AI images inside production until reviewed and approved.
- No images that imply exact product photos, model fit, live stock, or active affiliate status.
- No clover/trefoil logo if `Trefel` is used later.
